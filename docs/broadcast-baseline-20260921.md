## 1. 主机匹配基线（算法本身）

用整章音频滑窗标定，25 秒窗口 / 8 秒步长，54 个有效窗口（`tool/broadcast_span_tuning_test.dart`）：

| 指标 | 值 | 含义 |
|---|---|---|
| 命中率 | **0.98** | 54 个窗口里 53 个给出经文候选 |
| 平均覆盖率 | **0.71** | 候选原文被转写覆盖的比例 |
| 跨度膨胀率 | **0.17** | 候选参考词数 > 转写词数 ×1.6 的比例 |
| 推进回退率 | **0.00** | 相邻窗口候选节号倒退的比例 |
| 平均跨度 | **2.23 节** | 跨度分布：1 节×2、2 节×37、3 节×14 |

参数灵敏度（实测）：

- `spanPenalty` 在 0 / 0.02 / 0.05 / 0.1 / 0.2 五档下结果**完全相同**；
- `maxSpan` 4 与 6 **完全相同**（25 秒窗口最多用到 3 节）。

原因见[实施记录 §1.4](broadcast-implementation-20260921.md)：候选裁决以解释比例分带优先，
排序分只在同带内参与比较。因此这两个常数保持 `0.1` / `4`，不做无收益调整。

## 4. 翻译质量基线（必须单独看待）

机器翻译固定 ML Kit，阿→中经英语中转。**实测存在明显错译**，因此译文质量
不能由识别指标推导：

| 位置 | 原文（节选） | ML Kit 中文输出 | 正确大意 |
|---|---|---|---|
| `67:8` | «تَكَادُ تَمَيَّزُ مِنَ ٱلْغَيْظِ كُلَّمَآ أُلْقِىَ فِيهَا فَوْجٌ سَأَلَهُمْ خَزَنَتُهَآ أَلَمْ يَأْتِكُمْ نَذِيرٌ» | 「他制作了一名军团问他们」 | 火狱几乎因愤怒而破裂，每当有一群人被投入其中，其守卫就问他们：难道没有警告者降临你们吗？ |
| `67:9` | «قَالُوا۟ بَلَىٰ قَدْ جَآءَنَا نَذِيرٌ…» | 「他给了他们一个团，让他们留住你。」 | 他们说：不然，警告者确已降临我们…… |

来源标记是正确的（`machineCanonical`，输入为标准原文而非转写），问题在**引擎能力**，
不在链路。当前没有可分发的中英校订译本，`curatedEdition` 路径恒为空。

## 6. 明确不算达标的部分

以下不是「参数没调好」，而是**尚未验证**，不能由本文数值推断：

1. **真机匹配率 86% 只是单设备、单诵读者、单次播放的结果**。没有人工标注的节级
   ground truth，没有多诵读者、多距离、多底噪条件的数据；实施方案 §11.3 的验收矩阵
   （≥30 分钟、≥3 位诵读者、库外负样本集、P95 延迟）一项未做。
2. **翻译质量远未达标**：上表的错译是引擎能力边界，且中文效果不能用英文结果推定。
   没有人工语义评审，因此「译文可用」不成立。
3. **未匹配 17%（预览）的构成未逐条归因**：其中多少是真库外内容（章前求护词、
   解说、其他章节）、多少是拾音质量导致，尚未分开统计。
4. **段落级时延**：预览周期 1 s、终稿 2.3–2.6 s 是单次观测，未做 P95 统计。
5. **拾音条件的影响**（距离/音量/底噪）完全没有对照数据。
